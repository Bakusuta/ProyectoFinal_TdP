# ProyectoFinal\_TdP

#### Descripción

El juego presenta una experiencia interactiva donde el jugador avanza por medio de textos, decisiones numéricas, combates por turnos, administración de inventario, sistema económico y una tienda de objetos. La aventura está dividida en capítulos donde el jugador debe superar diferentes combates para avanzar en la historia



#### Sinopsis

El Guardián del Tiempo reinicia la historia y crea una nueva era, el jugador toma el papel de un campeón del Reino de la Tierra. La aventura comienza en Fengjian, donde el protagonista vive una vida tranquila junto a su mejor amigo Kung Lao, hasta que son puestos a prueba por su maestra la señora Bo. Luego de superar la prueba conocen al Dios del fuego Liu Kang quien les pide que se unan a el para ser los campeones de la tierra para asi enfrentar en un torneo a la gente del mundo exterior y calmar los deseos de la guerra de la gente exterior. El objetivo final es derrotar a los campeones enemigos y vencer al General Shao para proteger la paz entre los reinos



#### Requisitos para ejecutar el programa

Para compilar y ejecutar el juego se necesita:

* Sistema operativo Windows
* Compilador compatible con C++
* Visual Studio recomendado
* Consola de comandos o terminal
* Librerías estándar de C++
* Compatibilidad con las librerías Windows.h y conio.h



#### Pasos para compilar y ejecutar

El juego utiliza archivos de musica externos, por lo que es importante colocar la carpeta de musica antes de ejecutar el programa

###### Pasos:

1. Abrir el proyecto en Visual Studio
2. Compilar el proyecto en modo Debug o Release
3. Localizar la carpeta donde se generó el archivo ejecutable .exe (x64/debug)
4. Descarga la carpeta de musica en el drive de este enlace  https://drive.google.com/file/d/1EvXnSSLcs1bX76ki1LtQsuYu36G7lLlG/view?usp=sharing 
5. descomprimir la carpeta musica y sacar todos los archivos de la carpeta para que esten junto al ejecutable .exe
6. ejecutar el juego

IMPORTANTE: si las musicas no están junto al ejecutable, el juego podrá abrir pero la música no se reproducirá correctamente
